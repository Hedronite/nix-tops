### Added

- `fixtures/adopter/`: a flake shaped like an adopter's that re-exports the runner, with the kit locked as the relative path `../..` and its own nixpkgs pin.
- `fixtures/adopter/measure.py`: times `nix run .#nixtops -- version` on a store with neither the runner nor a Rust toolchain and lists the store paths fetched and built.
- `.github/workflows/cold-start.yml`: three runs each on `ubuntu-latest` and `macos-15`, by dispatch and on a pull request that changes the measurement or the kit's lock. The time is reported, not gated. No binary cache beyond the Nix default and no prebuilt binary.
