### Added

- `nixtops check` reads `nix-tops.toml`, validates it against `schema/nix-tops.schema.json` (embedded at build time, one source), and runs the section 12 checks that need no outputs: a failure exits 2 and names its key. It refuses `facet` (a profile key), an unknown key, a wrong type and an unknown facet; refuses `enforce = "advisory"` (protocol 0.2.0 has no exemption key); fails an expired `[[warnings.allow]]` entry, a missing baseline under `ratchet`, and a `nix-tops` input that follows nixpkgs in `flake.lock`; reports each facet as profile found, specified-unproven or no profile; and exits 3 when the host Nix is below the daemon floor.
- `nixtops init --facet <f>` writes `nix-tops.toml`, `.github/workflows/nix-tops.yml` (from `config/workflow.template.yml`) and the `AGENTS.md` section between the template's markers. It prints the `flake.nix` lines and never edits `flake.nix`, refuses to overwrite without `--force`, and a second run is byte-identical. Goldens for each facet live in `crates/nixtops/tests/goldens/`.
- Facet profiles are embedded from `profiles/`, one `include_str!` per file, with a test that fails on a profile file that is not embedded. `config::schema::validator` is public so the report check can validate through it.
