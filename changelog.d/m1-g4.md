### Added

- `nixtops gate [<path>]`: gates 1 and 3 and the report. The config is checked first (exit 2 for an invalid config, 3 for a host below the floor); then `source` (N-04: every `.nix` file under the flake root is tracked, a file staged and not committed counts as untracked, `.direnv` is exempt, in CI the tree is clean; N-05: `flake.lock` is committed and current, judged with `--no-update-lock-file`) and `eval` (`nix flake check --no-build --all-systems` under `abort-on-warn` with import from derivation off, the inventory of every output so one error does not hide the others, configuration build roots, `config.warnings` of every configuration read as data, the `nix` command's own diagnostics classified by `laws/diagnostics.toml` with an unknown line failing, the `[[warnings.allow]]` ledger, and the collect re-run after a warning stops the run). A failed layer stops the run unless `--keep-going`; the layers after it are `not-run` with the reason. `--only <layer>`, `--system <s>`, `--json`, `--base` and `--dry-run` (refused when `CI` is set) are accepted.
- `.nix-tops/report.json` is written on every run, including a run that stopped before any layer (every layer `not-run`, with the reason), and validates against `schema/gate-report.schema.json`. A layer that is switched off is `skip` with its reason; one that is on and not built in this version (`lint`, `build-test`, `coverage`, `facet-layers`, `laws`) is `not-run`, which fails the gate. A zero-output flake fails. An output that is not a derivation is reported at `instantiated` (§6.1), the others at `evaluated`.
- `nixtops gate --evaluator host`: the host's own Nix judges instead of the kit's pinned CppNix (the `determinate` job of §11). The outputs are listed one attribute at a time with that Nix; the Determinate-only settings are turned off (`lazy-trees false`, `eval-cores 1`); the report's baseline key names the implementation. The one §12 row.
- `nixtops report [<path>] [--format text|json]`: renders the last report.
- `fixtures/gates/`: nine flakes (a renamed NixOS option, a renamed standalone Home Manager option, an unknown option, an omitted declared system, import from derivation, an allowed warning, an expired ledger entry, an unclassified diagnostic, a clean flake), each with `expected.json`.
- `docs/evidence/2026-11-18-gates/`: the fixtures on a Determinate daemon host (pinned judge, and `--evaluator host`) and on a CppNix daemon host.
- The inventory reads a flake through its own reference, so a git tree with uncommitted edits is evaluated from its tracked files (an untracked `.nix` file is not read; gate 1 still refuses it).
- `[layers]` is read: a layer switched off with `{ enabled = false, reason }` is `skip` with that reason; one that is on and not built in this version is `not-run` and fails the gate. A reason that is only whitespace is no reason (exit 2, naming the key). With the laws layer switched off the text says laws are not enforced in this run. Gates 1 and 3 cannot be switched off (the schema refuses the keys).
